The funniest one-line apology from an office printer: it only works when IT is
watching — the rest of the time it jams, out of professional respect.

## Run it

```sh
python3 main.py
```

Writes one line (99 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
